# 完成内容复制块

日报和周报生成完成后，仅在存在实际完成项时追加一个原生可复制的 `text` 代码块。

## 内容规则

- 基于“今日完成”或“本周完成”的成果和说明重新提炼，不要机械复制报告正文。
- 去掉加粗标题、短哈希和原编号。
- 不包含项目概览、风险、数据说明或其他正文。
- 多个仓库的全部说明按报告顺序展平，统一从 `1，` 开始连续编号。
- 使用中文逗号连接编号和说明，例如 `1，在 ...`。
- 每条说明规范为一个自然段；换行和连续空白折叠为单个空格。
- 重点写清楚用户或工程获得了什么功能、交互效果或稳定性改进。
- 不显示文件名、扩展名、组件名、类名、函数名、变量名等实现细节。
- 每条优先使用“完善、新增、优化、统一”等动作开头，避免罗列改动清单。

例如，不写“在 `FlightList.vue`、`Registration.vue` 中增加折叠展示”，应写：

```text
2，旅客卡片支持展开查看随行人员信息，并优化展开动画和内容过渡，提升信息较多时的浏览体验。
```

## 放置方式

在“数据说明”之后、不添加额外栏目标题，直接输出一个围栏代码块：

````markdown
```text
1，第一条完成说明。
2，第二条完成说明。
```
````

代码块本身由 Codex 提供原生复制按钮。不要生成 HTML、JavaScript、剪贴板脚本或独立可视化文件。

零完成项时不生成复制块。
