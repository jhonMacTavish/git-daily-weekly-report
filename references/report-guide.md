# 中文日报与周报写作指南

## 数据映射

- 标题日期使用 `period.until_date`。
- “项目”由 `project.name` 和 `project.technology` 组成，例如 `VIPCSP 贵宾服务前端（Vue）`；technology 为空时不要猜测。
- “仓库”使用 `repositories[].path`。
- “提交”“涉及文件”“代码行”“时段”分别使用 `commit_count`、`stats.files_changed`、`stats.additions/deletions`、`stats.time_range`。
- “数据说明”中的身份变体来自 `matched_authors` 和 `resolved_author_values`；只写实际参与统计的姓名和邮箱。
- 长区间或页面结构调整产生大段移动时，说明代码行数不等于净新增。

## 日报模板

```markdown
工作日报 · YYYY-MM-DD

**项目**：项目名（技术栈）
**仓库**：/absolute/repo/path
**提交**：8 次 ｜ **涉及文件**：6 个 ｜ **代码行**：+1465 / −1403 ｜ **时段**：09:37–16:21

## 今日完成

1. **概括后的成果标题**（abc1234）
   说明关键文件、具体改动和最终效果。

2. **另一项成果**（def5678、ghi9012）
   合并描述同一主题的相关提交及其结果。

## 风险与关注点

- 只写有变更依据的运维、回归、兼容或发布注意事项。

## 数据说明

- 统计口径：仅本人提交，作者身份合并 `name`、`email` 等变体。
- 代码行数包含结构调整产生的大段移动，不代表同量净新增。
```

## 周报模板

```markdown
工作周报 · YYYY-MM-DD 至 YYYY-MM-DD

**项目**：项目名（技术栈）
**仓库**：/absolute/repo/path
**提交**：24 次 ｜ **涉及文件**：18 个 ｜ **代码行**：+2300 / −1200 ｜ **时段**：10-19 09:12–10-23 18:40

## 本周完成

1. **概括后的主要成果**（abc1234、def5678）
   合并相关提交，说明完成的工程结果、涉及范围和最终效果。

2. **另一项主要成果**（ghi9012）
   说明关键实现及对项目的影响。

## 风险与关注点

- 只写有变更依据的风险或回归关注点。

## 数据说明

- 统计口径：仅本人提交，作者身份合并 `name`、`email` 等变体。
- 代码行数包含结构调整和移动，不代表同量净新增。
```

## 格式硬约束

- 标题不使用 `#`，格式为 `工作日报 · 日期` 或 `工作周报 · 起始日期 至 结束日期`。
- 三行概览必须保持“项目和仓库各一行，提交/文件/代码行/时段合为一行”的结构。
- 统计行使用全角分隔符 `｜`，删除行数使用减号 `−`，时段使用连接号 `–`；跨天时段写成 `MM-DD HH:MM–MM-DD HH:MM`。
- 每个成果条目只能有一个标题行和一个缩进说明段；哈希写在标题后的中文括号中。
- 同一主题包含多个提交时，将全部相关短哈希放在同一组括号内，使用 `、` 分隔。
- 标题和项目概览后只能依次出现完成栏目、风险栏目、数据说明栏目，不添加总结、概览或证据清单。
- 多仓库分别输出完整报告块，中间使用 `---` 分隔。
- 日报和周报最后都添加一个 `text` 围栏代码块；Codex 会为该代码块提供原生复制控件。
- 复制代码块位于“数据说明”之后，不增加 Markdown 栏目标题，也不使用 HTML、JavaScript 或独立可视化文件。
- 复制代码块不是正文说明的原文副本，而是面向功能与结果的二次提炼。
- 不显示文件名、扩展名、组件名、类名、函数名或变量名；用户可见的功能名称可以保留。

## 风险与空结果

- 风险必须来自实际变更，例如构建产物移出版本控制、路由或入口行为变化、配置/迁移要求、重大兼容性调整。
- 没有可识别风险时写“暂无需要特别说明的风险。”，不要用空泛套话填充。
- `total_commits` 为 0 时，保留项目概览、三个栏目，并在完成栏目写“当日无提交”或“本周无提交”。
- 零提交时统计行使用 `0 次`、`0 个`、`+0 / −0`、`—`。

## 保存

默认直接在对话中返回 Markdown。用户明确要求保存时，优先使用用户指定路径；未指定时使用当前目录下的：

- `git-daily-weekly-report-YYYY-MM-DD-daily.md`
- `git-daily-weekly-report-YYYY-MM-DD_YYYY-MM-DD-weekly.md`

复制代码块会随 Markdown 一起保留。内容提取和格式见 [completion-copy-block.md](completion-copy-block.md)。
